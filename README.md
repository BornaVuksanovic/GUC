# GUC
* Cross-platform mobilna aplikacija koja pomaže korisnicima u postizanju dnevnih ciljeva hidratacije i praćenje unosa vode u stvarnom vremenu.

### Ključna postignuća i stečena znanja:
* Asinkrono programiranje: kompletan protok podataka koristeći async/await, čime se osigurava neometano (non-blocking) 
korisničko iskustvo tijekom komunikacije između React Native aplikacije i Node.js backenda.

* Upravljanje sesijama na mobilnom uređaju: sigurno pohranjivanje JWT tokena koristeći AsyncStorage, 
što omogućuje prijavu korisnika (Auto-login) i sigurnu autorizaciju pri svakom API pozivu.

* NoSQL Modeliranje podataka: Dizajnirao sam fleksibilne MongoDB sheme koristeći Mongoose za efikasno pohranjivanje
povijesti unosa vode, optimizirajući upite za brzo dohvaćanje dnevne statistike.

* Autentifikacija i ruting: JWT autorizacija s navigacijskim sustavom aplikacije (React Navigation), 
osigurava da su privatne rute dostupne isključivo autentificiranim korisnicima.

* Full-stack integracija: Povezao sam mobilnu aplikaciju s backendom hostanim na Renderu

### Tehnološki Stog (Tech Stack):
* Mobilni Frontend:  React Native, Expo, JavaScript
* Backend:  Node.js, Express.js
* Baza podataka:  MongoDB, Mongoose ODM
* Sigurnost:  JWT, bcrypt enkripcija
* Pohrana podataka:  AsyncStorage
* Infrastruktura:  Render.com (Backend hosting)
